# Study02_ToDoList

하루 10~20개의 할 일을 관리하는 **개인용 할 일 관리 웹 앱**입니다.
설치나 서버 없이 브라우저에서 바로 실행되고, 새로고침하거나 브라우저를 닫아도 데이터가 남습니다.

**배포 주소**: https://kimlooa1004-blip.github.io/Study02_ToDoList/

## 기능

- 할 일 추가 (Enter 또는 추가 버튼)
- 카테고리 분류: 업무 / 개인 / 공부 (색 배지로 구분)
- 새로 추가한 항목이 맨 위에 표시됨
- 브라우저 `localStorage`에 자동 저장 (새로고침해도 유지)
- 저장된 데이터가 깨졌을 때 안내 문구를 보여 주고 빈 목록으로 시작

> 수정·삭제·완료 체크·필터·진행률은 [PRD](./PRD.md)의 다음 단계에서 추가합니다.

## 파일

| 파일 | 내용 |
|---|---|
| `index.html` | 앱 전체 (HTML, CSS, 자바스크립트) |
| `PRD.md` | 제품 요구사항 문서 |

## 실행 방법

- **배포 주소로 열기**: 위 주소에 접속합니다.
- **내 컴퓨터에서 열기**: `index.html`을 더블클릭합니다.

## GitHub Pages로 배포하기

1. 저장소 루트에 `index.html`을 올립니다.
2. 저장소의 **Settings → Pages**로 이동합니다.
3. **Source**를 `Deploy from a branch`로 두고, Branch는 `main` / `/ (root)`를 선택한 뒤 **Save**를 누릅니다.
4. 1~2분 뒤 위의 배포 주소로 접속됩니다. 저장소 이름을 바꾸면 주소도 함께 바뀝니다.

## 데이터 저장 방식

- 데이터는 사용 중인 브라우저의 `localStorage`(키: `todo-app-v1`)에만 저장됩니다. 서버로 보내지 않습니다.
- 브라우저와 기기마다 데이터가 따로입니다. 사이트 데이터를 지우거나 시크릿 창을 쓰면 목록이 사라집니다.
