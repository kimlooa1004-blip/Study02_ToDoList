# Study02_ToDoList

개인용 **할 일 관리 앱**의 제품 요구사항 문서(PRD)를 모아 둔 저장소입니다.

## 앱 소개

- 하루 10~20개의 할 일을 관리하는 개인용 웹 앱
- 할 일 추가·수정·삭제, 완료 체크
- 카테고리 분류 (업무 / 개인 / 공부)와 진행률 보기
- 브라우저에서 바로 실행, 새로고침해도 데이터 유지 (`localStorage`)
- 순수 HTML·CSS·자바스크립트 (빌드·설치 없음)
